**Update src/app/controller/page.tsx:**
1. Add `dir={session?.language === 'ar' ? 'rtl' : 'ltr'}` to the outermost wrapper div. This propagates RTL to all descendant components automatically.
2. Add `language={session.language ?? 'en'}` prop to every screen component: <LanguageSelectScreen session={session} language={session.language ?? 'en'} /> etc.
3. Update the inline IdleScreen: use `const lang = session?.language ?? 'en'` and replace hardcoded text with `t(lang).tapToStart` and `t(lang).start`.

**Update all 7 screen components:**
Add `language: Language` to each component's Props type (import Language from @/types/database).

Replace every hardcoded English string with the appropriate `t(language).key` call:

- LanguageSelectScreen: title → `t(language).selectLanguage`. Note: the two language buttons themselves stay bilingual by design ("English" / "العربية") — do NOT replace these with i18n keys. They are the language selector and must always show both languages regardless of current language.

- AvatarSelectScreen: title → `t(language).chooseAvatar`

- NameEntryScreen: title → `t(language).enterName`, input placeholder → `t(language).namePlaceholder`, button → `t(language).continue`

- TrackSelectScreen: title → `t(language).chooseTrack`, each track button label → `t(language).trackName(track)`

- QuizScreen: question progress indicator → `t(language).questionOf(session.current_question + 1, 10)`

- QuestionResultScreen: correct feedback → `t(language).correct`, incorrect feedback → `t(language).incorrect`, score → `t(language).score(session.score, session.current_question + 1)`, "Next Question" button → `t(language).nextQuestion`, "See Final Score" button → `t(language).seeFinalScore`

- FinalResultScreen: score display → `t(language).finalScore(session.score)`, hired heading → `t(language).youreHired`, hired message → `t(language).hiredMessage`, not-hired heading → `t(language).wellGetBack`, not-hired message → `t(language).getBackMessage`, play again button → `t(language).playAgain`
