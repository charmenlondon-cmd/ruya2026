  <action>
Rewrite controller/page.tsx completely. Keep 'use client'. Remove all dev-scaffold code (STATE_ORDER array, cycling logic, Next State button).

New structure:

1. Use useSession() to get { session, loading, error }.
2. Track `creatingSession` in local state (boolean, init false). After loading is false and session is null and !creatingSession: set creatingSession=true and call createSession() (import from @/lib/session). This prevents duplicate session creation on re-renders. Do NOT call createSession unconditionally on mount.
3. Render an IdleScreen inline (no separate file) when session.state is 'idle' or 'screensaver':
   - Full-screen centred div with a "Tap to Start" heading (text-4xl font-bold text-white) and a large teal button "Start" that calls updateSession(session.id, { state: 'language_select' }).
4. Route to the correct screen component based on session.state:
   - 'idle' | 'screensaver' → inline IdleScreen
   - 'language_select' → <LanguageSelectScreen session={session} />
   - 'avatar_select' → <AvatarSelectScreen session={session} />
   - 'name_entry' → <NameEntryScreen session={session} />
   - 'track_select' → <TrackSelectScreen session={session} />
   - 'question_active' | 'answer_submitted' | 'question_result' | 'final_result' → placeholder: <div className="text-white text-xl p-8">Quiz interface coming in Plan 04-02</div>
5. Show a loading spinner while loading is true.
6. Show error text if error is non-null.
7. Wrap the entire return in: <div className="min-h-screen flex flex-col items-center justify-center p-6">
8. Each screen component receives only `session: Session` as prop. Components call updateSession(session.id, patch) directly (they import from @/lib/session themselves).
  </action>

  - "English" → updateSession(session.id, { language: 'en', state: 'avatar_select' })
  - "العربية" → updateSession(session.id, { language: 'ar', state: 'avatar_select' })
- Button style: bg-white text-aaah-dark-teal font-semibold rounded-2xl px-12 py-6 text-xl hover:bg-aaah-light-teal/20 active:scale-95 transition-all

**AvatarSelectScreen.tsx**
- Title: "Choose Your Avatar" (text-2xl font-bold text-white mb-6)
- Grid: grid grid-cols-5 gap-4, showing all 10 avatars in two conceptual rows (5 female, 5 male in same grid — they sort visually into rows automatically)
- Avatar filenames: female-avatar-1 through female-avatar-5, male-avatar-1 through male-avatar-5
- Each is a button wrapping a Next.js <Image>: circular (w-20 h-20 rounded-full object-cover), with a white semi-transparent bg on hover
- On tap: updateSession(session.id, { avatar_id: `female-avatar-${n}` or `male-avatar-${n}`, state: 'name_entry' })
