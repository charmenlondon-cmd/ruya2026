Replace `src/app/controller/page.tsx` with a minimal client component that:

1. Creates a new session on mount (calls `createSession()` from `@/lib/session`)
2. Subscribes to the session via `useSession()` — gets live updates back from DB
3. Renders:
   - Current session state in large text (e.g., `session.state`)
   - Session ID in small text (for debugging on the display side)
   - A "Next State →" button that cycles through the 10 session states in order

**State cycle order:**
```
idle → language_select → avatar_select → name_entry → track_select
→ question_active → answer_submitted → question_result → final_result → screensaver → idle
```

**Next State button handler:**
```typescript
const STATE_ORDER: SessionState[] = [
  'idle', 'language_select', 'avatar_select', 'name_entry', 'track_select',
  'question_active', 'answer_submitted', 'question_result', 'final_result', 'screensaver'
]

async function handleNextState() {
  if (!session) return
  const current = STATE_ORDER.indexOf(session.state)
  const next = STATE_ORDER[(current + 1) % STATE_ORDER.length]
  await updateSession(session.id, { state: next })
}
```

Import `updateSession` from `@/lib/session`, `createSession` from `@/lib/session`, `useSession` from `@/hooks/useSession`, `SessionState` from `@/types/database`.

Add `'use client'` at top of file.

**Layout:** Simple centered div. No Tailwind styling required beyond basic readability — this is a dev scaffold. Use `className="p-8 font-mono"` on the wrapper.

**On mount:** Call `createSession()` in a `useEffect(fn, [])`. Store the returned session ID in state (`sessionId`). Pass `sessionId` to... wait, `useSession()` takes no args per the hook design in 02-01. The hook will auto-discover the latest session. Since controller just created it, that's the one.

**Note:** If `useSession()` from 02-01 was implemented with no args (discovers active session), simply use it as-is. If it was implemented with a sessionId arg, pass the created session's ID. Read the 02-01-SUMMARY.md to determine the actual signature before implementing.

Replace `src/app/display/page.tsx` with a minimal client component that shows the live session state:

```typescript
'use client'

import { useSession } from '@/hooks/useSession'

export default function DisplayPage() {
  const { session, loading, error } = useSession()

  if (loading) return <div className="p-8 font-mono">Connecting...</div>
  if (error) return <div className="p-8 font-mono text-red-500">Error: {error}</div>
  if (!session) return <div className="p-8 font-mono">Waiting for game to start...</div>

  return (
    <div className="p-8 font-mono">
      <div className="text-sm text-gray-400 mb-2">Session: {session.id}</div>
      <div className="text-4xl font-bold">{session.state}</div>
      <div className="text-sm text-gray-400 mt-4">
        Lang: {session.language ?? '—'} | 
        Player: {session.player_name ?? '—'} | 
        Track: {session.track ?? '—'} | 
        Score: {session.score}
      </div>
    </div>
  )
}
```

This page is intentionally minimal — it will be completely replaced by Phase 5 display UI. Its only job is to prove the realtime subscription works.
