Create `src/hooks/useSession.ts` — a React client hook that returns the current live session:

```typescript
'use client'

import { useState, useEffect } from 'react'
import { supabase } from '@/lib/supabase'
import { getActiveSession } from '@/lib/session'
import type { Session } from '@/types/database'

interface UseSessionResult {
  session: Session | null
  loading: boolean
  error: string | null
}

export function useSession(): UseSessionResult
```

**Implementation:**
1. State: `session: Session | null`, `loading: boolean` (init true), `error: string | null`
2. `useEffect` on mount:
   a. Call `getActiveSession()` and set session (set loading false after)
   b. Open Supabase channel `game-session` with `supabase.channel('game-session')`
   c. `.on('postgres_changes', { event: '*', schema: 'public', table: 'sessions' }, handler)`
   d. Handler: 
      - On INSERT: if new row's created_at > current session's created_at (or no current session), setSession(payload.new)
      - On UPDATE: if payload.new.id === current session id, setSession(payload.new)
   e. `.subscribe()`
3. Cleanup: return a function that calls `supabase.removeChannel(channel)`
4. Wrap in try/catch, set error string on failure

**Important:** The payload.new from postgres_changes is typed as `Record<string, unknown>`. Cast it with `payload.new as Session`.

**Do NOT use useRef for the session inside the handler** — use a functional setState update or capture the value in the closure carefully to avoid stale closure bugs. Simplest: store session in state, use `setSession(payload.new as Session)` directly for UPDATE. For INSERT comparison, check `payload.new.created_at > (current snapshot)` by keeping a `sessionRef = useRef(session)` synced in a separate useEffect.

Actually simplest correct approach: On any INSERT, always setSession(payload.new as Session) — since controller creates sessions and display should follow. On UPDATE, setSession only if payload.new.id matches payload.old?.id or current session id. Use a ref to avoid stale closure:

```typescript
const sessionRef = useRef<Session | null>(null)
// sync ref
useEffect(() => { sessionRef.current = session }, [session])

// In the postgres_changes handler:
const handleChange = (payload: RealtimePostgresChangesPayload<Session>) => {
  if (payload.eventType === 'INSERT') {
    setSession(payload.new as Session)
  } else if (payload.eventType === 'UPDATE') {
    if (sessionRef.current && payload.new.id === sessionRef.current.id) {
      setSession(payload.new as Session)
    }
  }
}
```

Import types: `RealtimePostgresChangesPayload` from `@supabase/supabase-js`.
