<task type="auto">
  <name>Task 2: Build branded root layout</name>
  <files>src/app/layout.tsx</files>
  <action>
Replace the default `src/app/layout.tsx` generated by create-next-app with the AAAH branded version.

The root layout must:
1. Load Montserrat via `next/font/google` (Regular 400, SemiBold 600, Bold 700)
2. Apply Montserrat as the default font family via CSS variable
3. Set a dark teal gradient background as the page default
4. Include the AAAH dual-language logo in a slim top bar
5. Set `dir="ltr"` at the html level (individual pages override for RTL as needed)
6. Set `lang="en"` (controller page overrides for AR when needed)

```tsx
import type { Metadata } from 'next'
import { Montserrat } from 'next/font/google'
import './globals.css'
import Image from 'next/image'

const montserrat = Montserrat({
  subsets: ['latin'],
  weight: ['400', '600', '700'],
  variable: '--font-montserrat',
  display: 'swap',
})

export const metadata: Metadata = {
  title: 'Ruya Careers Fair 2026',
  description: 'AAAH Interactive Careers Fair Game',
}

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en" dir="ltr" className={montserrat.variable}>
      <body className="min-h-screen bg-aaah-gradient font-[var(--font-montserrat)] antialiased">
        <header className="flex items-center justify-between px-6 py-3 bg-black/20 backdrop-blur-sm">
          <Image
            src="/logos/aaah-logo-white.png"
            alt="Abdulla Al Arif Holding"
            width={180}
            height={48}
            priority
            className="h-10 w-auto object-contain"
          />
        </header>
        <main>{children}</main>
      </body>
    </html>
  )
}
```

After writing, run `npm run build` to confirm the layout compiles and no Image or font errors are thrown.
