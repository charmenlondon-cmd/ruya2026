**src/hooks/useHires.ts — add Realtime subscription:**

The hook currently fetches once on mount. Extend it to also subscribe to new inserts:

1. Import `supabase` channel utilities (already imported)
2. In the `useEffect`, after the initial fetch set-up, create a Realtime channel:
   ```
   const channel = supabase.channel('hires-feed')
   channel
     .on(
       'postgres_changes',
       { event: 'INSERT', schema: 'public', table: 'hires' },
       (payload) => {
         setHires((prev) => [...prev, payload.new as Hire])
       }
     )
     .subscribe()
   ```
3. Return cleanup: `return () => { supabase.removeChannel(channel) }`
4. The `useEffect` dependency array remains `[]` (subscribe once on mount).

Pattern exactly mirrors `useSession.ts` — same channel lifecycle, same cleanup.

**src/components/display/HiredNetworkCanvas.tsx — node entry animation:**

Add a `born` timestamp and `entryAlpha` to `HireNode`:
```ts
interface HireNode extends d3.SimulationNodeDatum {
  id: string
  hire: Hire
  img: HTMLImageElement | null
  born: number      // Date.now() when node was created
  entryAlpha: number  // 0.0 → 1.0 over ENTRY_MS
}
```
Add constant: `const ENTRY_MS = 600`

**In the merge-hires logic (when hires prop changes):**
- For existing nodes (id found in existingById): reuse the existing object as-is (preserves position, alpha already 1.0)
- For new nodes: set `born: Date.now(), entryAlpha: 0`, position at `x: cx + (Math.random()-0.5)*4, y: cy + (Math.random()-0.5)*4` (near centre so they animate outward naturally via cluster force)

**In the simulation `tick` handler (draw function):**

Before drawing each node, compute its current alpha and set canvas globalAlpha:
```
const now = Date.now()
for (const node of nodesRef.current) {
  node.entryAlpha = Math.min(1, (now - node.born) / ENTRY_MS)

  ctx.save()
  ctx.globalAlpha = node.entryAlpha
  // ... existing draw code (arc clip + drawImage/fillStyle + stroke) ...
  ctx.restore()
  // Reset globalAlpha is implicit via ctx.restore() if save/restore wraps it
}
```
Ensure `ctx.globalAlpha` is set inside the `ctx.save()`/`ctx.restore()` block so it doesn't leak between nodes.

**Backfill existing nodes on first render** — nodes loaded from the initial fetch should appear immediately (not fade in). When creating nodes for the initial `hires` array, set `born: Date.now() - ENTRY_MS - 1` so `entryAlpha` immediately resolves to 1.0. Only brand-new nodes arriving via the subscription hook get `born: Date.now()`.

To distinguish "initial load" from "live arrival": use a `mountedAt` ref:
```ts
const mountedAtRef = useRef<number>(Date.now())
```
In the merge logic: for any new node id, set `born = hires.length === nodesRef.current.length + 1 ? Date.now() : mountedAtRef.current - ENTRY_MS - 1`

Actually, simpler approach: store the set of "seen ids" at first render. On first call to `useEffect`, all hires get `born = Date.now() - ENTRY_MS - 1`. On subsequent calls (new hire arrives via Realtime → hires prop grows), only the brand-new id gets `born = Date.now()`.

Implementation: before the merge loop, build `knownIds = new Set(nodesRef.current.map(n => n.id))`. If `knownIds.has(id)` → existing node (reuse). If not → new node. New node born:
- `knownIds.size === 0` (first render, all nodes are "initial") → `born = Date.now() - ENTRY_MS - 1`
- `knownIds.size > 0` (simulation already running, this is a live arrival) → `born = Date.now()`

This correctly gives initial nodes instant opacity and live-arrival nodes the fade-in.
