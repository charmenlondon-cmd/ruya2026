Create `src/components/display/HiredNetworkCanvas.tsx`:

Mark `'use client'`. Import `useEffect, useRef` from react; `* as d3` from `d3`; `Hire` from `@/types/database`.

**Constants (define at module level):**

Track angles — 10 tracks each 36° apart (clockwise from top):
```
Engineering: 270°, Finance: 306°, Architecture & Design: 342°,
Human Resources: 18°, IT: 54°, Legal & Compliance: 90°,
Marketing: 126°, Operations & Supply Chain: 162°,
Project Management: 198°, Sales & Business Development: 234°
```
Store as `TRACK_ANGLE_DEG: Record<string, number>` — convert to radians when computing targets.

Track colours — 10 visually distinct colours (one per track, should contrast on dark background):
```
Engineering: '#60a5fa'        (blue)
Finance: '#34d399'            (emerald)
Architecture & Design: '#f472b6'  (pink)
Human Resources: '#fb923c'    (orange)
IT: '#a78bfa'                 (violet)
Legal & Compliance: '#fbbf24' (amber)
Marketing: '#f87171'          (red)
Operations & Supply Chain: '#2dd4bf'  (teal — distinct from aaah-teal)
Project Management: '#e879f9' (fuchsia)
Sales & Business Development: '#86efac'  (light green)
```
Store as `TRACK_COLOR: Record<string, string>`.

`const AVATAR_RADIUS = 26` — pixel radius of avatar circles.
`const CLUSTER_RADIUS_RATIO = 0.38` — cluster centres sit at 38% of the shorter canvas dimension from centre.

**Internal type:**
```ts
interface HireNode extends d3.SimulationNodeDatum {
  id: string
  hire: Hire
  img: HTMLImageElement | null
}
```

**Props:** `{ hires: Hire[] }`

**Refs:**
- `canvasRef = useRef<HTMLCanvasElement>(null)`
- `simulationRef = useRef<d3.Simulation<HireNode, never> | null>(null)`
- `nodesRef = useRef<HireNode[]>([])`

**useEffect (deps: [hires]):**

1. Get canvas from ref; if null return.
2. Size canvas: `canvas.width = canvas.parentElement?.offsetWidth ?? window.innerWidth; canvas.height = canvas.parentElement?.offsetHeight ?? window.innerHeight`
3. `const ctx = canvas.getContext('2d'); if (!ctx) return`
4. `const cx = canvas.width / 2; const cy = canvas.height / 2`

5. **Merge hires into nodes** — preserve existing node positions so the simulation doesn't reset:
   - Build `existingById` map from `nodesRef.current` keyed by `id`
   - Map `hires` → `HireNode[]`: for existing id, reuse the existing node object; for new id, create `{ id, hire, img: null, x: cx + (Math.random()-0.5)*20, y: cy + (Math.random()-0.5)*20 }`
   - Assign `nodesRef.current = newNodes`

6. **Preload avatar images** for nodes with `img === null`:
   - For each such node: `const img = new Image(); img.src = '/avatars/' + node.hire.avatar_id + '.png'; img.onload = () => { node.img = img }`

7. **Set up or restart simulation:**
   - If `simulationRef.current` is null, create: `simulationRef.current = d3.forceSimulation<HireNode>()`
   - Always call: `.nodes(nodesRef.current).alpha(0.6).restart()`
   - Apply forces:
     - `.force('collision', d3.forceCollide<HireNode>(AVATAR_RADIUS + 3))`
     - `.force('charge', d3.forceManyBody<HireNode>().strength(-20))`
     - `.force('cluster', clusterForce)` — custom force (see below)
     - `.force('center', d3.forceCenter(cx, cy).strength(0.04))` — weak global pull

8. **Custom cluster force** (define as a closure capturing `cx, cy, canvas.width, canvas.height`):
   ```
   const clusterR = Math.min(cx, cy) * CLUSTER_RADIUS_RATIO
   const clusterForce = (alpha: number) => {
     for (const node of nodesRef.current) {
       const angleDeg = TRACK_ANGLE_DEG[node.hire.track] ?? 0
       const rad = (angleDeg * Math.PI) / 180
       const tx = cx + Math.cos(rad) * clusterR
       const ty = cy + Math.sin(rad) * clusterR
       node.vx = (node.vx ?? 0) + (tx - (node.x ?? cx)) * alpha * 0.45
       node.vy = (node.vy ?? 0) + (ty - (node.y ?? cy)) * alpha * 0.45
     }
   }
   ```

9. **Draw function** (called on every simulation tick):
   ```
   simulation.on('tick', () => {
     ctx.clearRect(0, 0, canvas.width, canvas.height)
     for (const node of nodesRef.current) {
       const x = node.x ?? cx
       const y = node.y ?? cy
       ctx.save()
       ctx.beginPath()
       ctx.arc(x, y, AVATAR_RADIUS, 0, Math.PI * 2)
       ctx.clip()
       if (node.img) {
         ctx.drawImage(node.img, x - AVATAR_RADIUS, y - AVATAR_RADIUS, AVATAR_RADIUS * 2, AVATAR_RADIUS * 2)
       } else {
         // Fallback: filled circle in track colour
         ctx.fillStyle = TRACK_COLOR[node.hire.track] ?? '#ffffff'
         ctx.fill()
       }
       ctx.restore()
       // Coloured ring
       ctx.beginPath()
       ctx.arc(x, y, AVATAR_RADIUS, 0, Math.PI * 2)
       ctx.strokeStyle = TRACK_COLOR[node.hire.track] ?? '#ffffff'
       ctx.lineWidth = 3
       ctx.stroke()
     }
   })
   ```

10. **Cleanup:** `return () => { simulationRef.current?.stop() }`

  />
